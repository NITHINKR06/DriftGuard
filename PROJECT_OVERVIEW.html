🛡️ DriftGuard

Advanced Network Intrusion Detection with Cross-Dataset Validation

An ensemble machine learning system that detects network anomalies and adapts to dataset shifts, combining Isolation Forest, Autoencoders, and LSTM models with explainable AI for security analysts.

⚙️ How It Works 🚀 Get Started

🎯 What is DriftGuard?

Solving the dataset shift problem in cybersecurity

💡 The Problem

Traditional intrusion detection systems fail when deployed in environments different from where they were trained. A model trained on university network traffic may produce thousands of false alerts in a corporate network, leading to alert fatigue and missed real threats.

✅ The Solution

DriftGuard uses an ensemble of complementary anomaly detection models, validated across different datasets (CICIDS2017 → UNSW-NB15), with built-in distribution shift analysis and explainable predictions to maintain performance across diverse network environments.

🤖 Three Detection Engines

Complementary approaches for robust anomaly detection

🌲

Isolation Forest

Tree-based outlier detection that isolates anomalies based on feature randomness. Fast, effective for high-dimensional data. Weight: 30%

🧠

Autoencoder

Dense neural network (77→50→25→50→77) that learns normal patterns through reconstruction. Flags traffic based on MSE. Weight: 40%

⏱️

LSTM Autoencoder

Bidirectional LSTM capturing temporal dependencies across 10-timestep windows. Detects sequence-based anomalies. Weight: 30%

⚙️ How It Works

From raw traffic to actionable insights

1

Data Preprocessing

Raw network traffic (CICIDS2017/UNSW-NB15) → Feature extraction → Cleaning (NaN, infinity) → Scaling (StandardScaler) → 77-feature matrix saved as .npy

2

Model Training

Train all three models on benign traffic only from CICIDS2017. Models learn what "normal" looks like, then flag deviations as anomalies during inference.

3

Ensemble Scoring

Normalize model outputs to [0,1] → Apply weighted fusion (0.3×IF + 0.4×AE + 0.3×LSTM) → Generate unified risk score → Classify as HIGH/MEDIUM/LOW severity

4

Explainability

SHAP values explain which features contributed to each prediction. Security analysts see waterfall plots showing feature importance for flagged traffic.

5

Cross-Dataset Validation

Align UNSW-NB15 features to CICIDS2017 space → Apply trained models → Measure performance degradation → Analyze distribution shifts using KS tests and PSI
